Privacy Policy

Last updated: August 22, 2026

Core summary: DBV Teleprompter is built on strict privacy-by-design principles. It does not collect, transmit, or store on any external servers any personal information or script content. There are no user accounts, no advertisements, no third-party analytics, and zero telemetry. All text processing is performed 100% locally on your own device.

1. Local Script and Text Processing

All scripts and text files that you open, edit, or prompt in DBV Teleprompter (including .txt, .md files, or directly pasted text) are processed solely in your computer's local memory.

The application has no remote servers, databases, or cloud backends. Your scripts and notes never leave your computer and are never transmitted across the network.

2. Data Stored on Your Device

To provide a seamless experience when resuming your work, DBV Teleprompter saves the following preferences strictly on your device's local storage (localStorage):

  • Working draft: The last active script title and content so you never lose your draft when reopening the app.
  • Playback preferences: Your selected scroll speed and reading font size.
  • Interface settings: Your chosen visual theme (Dark Mode or Light Mode) and language (English or Spanish).
  • Key bindings: Custom keyboard shortcut configurations set in the slide-in panel.

This data stays exclusively on your machine and can be cleared at any time by clearing your browser local storage or uninstalling the desktop app.

3. Network Connections & Offline-First Operation

DBV Teleprompter is designed with an offline-first architecture:

  • Zero external CDN dependencies: All typography (Newsreader and Nunito), icons, and assets are self-hosted and packaged within the application.
  • Zero telemetry or tracking: The application does not send analytics, telemetry, or diagnostic heartbeats to any remote server.

4. Microsoft Store Installation

If you install DBV Teleprompter via the Microsoft Store, Microsoft may collect anonymous telemetry, download stats, and OS error diagnostics according to its own privacy policy. For further information on how Microsoft handles this data, please refer to the Microsoft Privacy Statement.

5. Open Source & Transparency

DBV Teleprompter is free and open-source software licensed under the MIT License. The complete source code is publicly available for inspection at github.com/davidbuenov/dbv-teleprompter.

6. Contact

If you have any questions or feedback regarding this privacy policy, you can contact the author via GitHub Issues or via the personal website davidbuenov.com.
